Tags and Attributes

Grundlagen

  • HTML = Hypertext Markup Language, 1991, Tim Berners-Lee
  • Keine Programmiersprache, sondern Auszeichnungssprache
  • CSS = Aussehen, JavaScript = Dynamik
  • HTML5 ist ein "living document" (WHATWG)

Tags

  • Aufbau: Starttag, Inhalt, Endtag
  • Attribute stehen im Starttag: name="wert"
  • Void-Elemente ohne Endtag: br, img, hr, link, meta, input
  • Verschachteln: innere Tags zuerst schließen

Grundgerüst

  • DOCTYPE html am Anfang, wird nicht geschlossen
  • html enthält head und body
  • head = Titel, CSS, JS, Meta
  • body = sichtbarer Inhalt
  • charset UTF-8 für Umlaute
  • viewport für mobile Geräte

Wichtige Elemente

  • p = Absatz, br = Zeilenumbruch (nie für Abstände)
  • h1 bis h6 = Überschriften, strukturieren die Seite
  • img = Bild, braucht src und alt
  • ul = Punkte, ol = Nummern, beide mit li
  • dl, dt, dd = Definitionsliste
  • a = Link, Ziel im href
  • table, tr, th, td = Tabelle
  • thead, tbody, tfoot = Bereiche; rowspan, colspan = Zellen verbinden
  • strong, em, mark = wichtig, betont, hervorgehoben
  • b, i, s sind deprecated

Globale Attribute

  • id = eindeutiger Name
  • class = CSS-Klassen
  • style = CSS direkt am Element
  • title = Zusatzinfo
  • lang = Sprache

Inline und Block

  • Inline: wie ein Zeichen im Text – strong, em, a, img, span
  • Block: eigene Zeile, volle Breite – h1-h6, p, ul, table, div
  • Änderbar mit der CSS-Eigenschaft display

Gruppieren

  • div = Block, span = Inline, beide ohne Bedeutung
  • Semantisch: header, nav, main, section, article, aside, footer
  • Auch: figure, figcaption, details, summary, time
  • Vorteil: Screenreader und Reader Mode erkennen die Bereiche

Accessibility

  • Screenreader lesen die Seite vor
  • Überschriften-Hierarchie = Navigation
  • Überschriften nie nur für größere Schrift verwenden
