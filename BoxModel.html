Box Model

Aufbau

  • Von innen nach außen: content, padding, border, margin
  • width und height bestimmen die Größe des Inhalts
  • padding = Abstand Inhalt zum Rahmen
  • border-width = Dicke der Rahmenlinie
  • margin = Abstand nach außen zu anderen Elementen

Einzelwerte

  • Für jede Seite einzeln: padding-top, margin-bottom, border-left-width
  • Gibt es bei allen drei Eigenschaften

Shorthands

  • Vier Werte: oben, rechts, unten, links (Uhrzeigersinn)
  • Drei Werte: oben, links und rechts, unten
  • Zwei Werte: oben und unten, links und rechts
  • Ein Wert: alle vier Seiten gleich
  • border setzt width, style und color in einer Zeile

box-sizing

  • content-box ist der Standard
  • Dabei gilt width nur für den Inhalt, padding und border kommen dazu
  • Element wird also breiter als angegeben
  • border-box: width ist die Gesamtbreite inklusive padding und border
  • border-box ist praktischer beim Rechnen

display

  • none = Element wird ausgeblendet
  • inline = kein width und height, nur seitliche Abstände, andere Elemente daneben
  • block = eigene Zeile, alle Abstände, width und height möglich
  • inline-block = daneben erlaubt, aber mit width, height und allen Abständen
  • flex und grid machen das Element zum Layout-Container

Tipp
