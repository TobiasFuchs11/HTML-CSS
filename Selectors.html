Selectors

CSS-Syntax

  • CSS = Cascading Style Sheets, trennt Inhalt und Darstellung
  • Regel = Selektor plus Deklarationen in geschweiften Klammern
  • Deklaration = Eigenschaft, Doppelpunkt, Wert
  • Mehrere Deklarationen mit Strichpunkt trennen

CSS einbinden

  • Inline: style-Attribut am Element, nur im Notfall
  • Internal: style-Element im head, nicht wiederverwendbar
  • External: link-Element im head, Standard und am besten

Vererbung

  • Vererbt werden Farben und Schriften
  • Nicht vererbt werden Borders und Margins
  • Mit dem Wert inherit erzwingbar

Einfache Selektoren

  • Element: h1 wählt alle h1
  • ID: Raute plus Name, nur ein Element
  • Klasse: Punkt plus Name
  • span.important = nur span mit dieser Klasse
  • Zwei Klassen hintereinander = beide nötig
  • Universal: Stern wählt alles
  • Attribut: eckige Klammern, z. B. lang="en"

Kombinatoren

  • Beistrich = Selektorliste, wählt beide
  • Leerzeichen = Descendant, irgendwo darin
  • Größerzeichen = Child, nur direkte Kinder
  • Plus = Adjacent Sibling, direkt danach
  • Tilde = General Sibling, alle danach auf gleicher Ebene

Pseudo-Klassen

  • hover, active, visited = Zustand des Elements
  • before und after fügen mit content Text ein
  • first-letter formatiert den ersten Buchstaben
  • nth-child wählt z. B. jedes zweite Kind
  • Ein Doppelpunkt = Pseudo-Klasse, zwei = Pseudo-Element

Spezifität

  • Drei Zahlen: IDs, Klassen, Elemente
  • Element = 0,0,1 / Klasse = 0,1,0 / ID = 1,0,0
  • Gelesen wie eine Zahl gewinnt der größere Wert
  • Kein Übertrag: 0,1,0 ist größer als 0,0,11

Cascade

  • 1. Importance: !important schlägt alles
  • 2. Spezifität: Inline-Styles sind am stärksten
  • 3. Source Order: bei Gleichstand gewinnt die letzte Regel
