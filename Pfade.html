Absolute and Relative Paths

URI

  • URI adressiert eine Ressource im Web, URL ist ein Spezialfall
  • Teile: scheme, authority, path, query, fragment
  • Pflicht sind nur scheme und path

Die Teile

  • scheme = Protokoll: http, https, ftp, mailto, tel
  • authority = Hostname oder IP, optional Port
  • path = Weg zur Ressource, getrennt mit Slash
  • query = Key-Value-Paare nach dem Fragezeichen
  • fragment = Sprungziel nach der Raute, meist eine id

Absolute Pfade

  • Vollständige URI in href oder src
  • Nachteil: bricht beim Verschieben der Seite

Relative Pfade

  • Nur Dateiname = aktuelles Verzeichnis
  • ordner/datei = Unterverzeichnis
  • Zwei Punkte und Slash = eine Ebene höher
  • Lässt sich mehrfach wiederholen
  • Vorteil: funktioniert auch nach dem Verschieben

Relativ zum Document Root

  • Pfad beginnt mit einem Slash
  • Startet immer im Wurzelverzeichnis der Website
  • Egal, in welchem Unterordner die aktuelle Seite liegt

Scheme-relativ

  • Pfad beginnt mit zwei Slashes ohne scheme
  • Übernimmt das Protokoll der aktuellen Seite
  • Heute: einfach immer HTTPS verwenden
